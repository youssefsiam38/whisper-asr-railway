# Assets

`icon.png` is a 512x512 mark drawn for this template: a speech waveform resolving into lines of
text, which is what the service does. It was made in `PIL` for this repository and is MIT licensed
along with the rest of it.

Whisper ASR Webservice publishes no logo of its own -- its documentation site uses a stock Material
Design glyph -- so nothing upstream is reused here. "Whisper" and "OpenAI" are marks of OpenAI, and
neither the upstream project nor this template is affiliated with or endorsed by OpenAI.
